## [2026-10-02] Max Bot API: CA Минцифры
**Категория:** инфраструктура
**Что неочевидно:**
`platform-api2.max.ru` падает с `UNABLE_TO_GET_ISSUER_CERT_LOCALLY` на Node без русского корневого CA.
**Решение / на что обращать внимание:**
Использовать `apps/api/certs/russian-trusted-ca-bundle.pem` через `maxClientOptions()` (undici Agent). Не отключать TLS глобально.

## [2026-10-02] Mini App URL в Max
**Категория:** деплой
**Что неочевидно:**
Выдуманный домен → Bad Request. `localhost` не принимается. Туннели (loca.lt / lhr.life / serveo) часто умирают → «no tunnel here» / пустая страница.
**Решение / на что обращать внимание:**
Нужен живой HTTPS. После смены туннеля **обновить ссылку в настройках бота Max**. Для прода — нормальный деплой, не туннель.

## [2026-10-02] Дубли ответов бота /start
**Категория:** infra
**Что неочевидно:**
Несколько `pnpm bot` → N одинаковых сообщений на одно /start.
**Решение / на что обращать внимание:**
Один процесс; lock `apps/api/.bot.lock`. Перед стартом убивать старые `src/bot/run.ts`.

## [2026-10-02] Cloudflare quick tunnel с этой сети
**Категория:** инфраструктура
**Что неочевидно:**
QUIC/TCP 7844 к Cloudflare часто блокируется → 530 / tunnel fail.
**Решение / на что обращать внимание:**
Пробовать serveo / localtunnel / localhost.run или деплой; не полагаться только на cloudflared.

## [2026-10-02] Amvera: Unknown configuration error
**Категория:** деплой
**Что неочевидно:**
Строгий `meta.toolchain.name: docker` + числовой `containerPort` иногда даёт «Unknown configuration error».
**Решение / на что обращать внимание:**
`meta.toolchain` должен быть **секцией** (`name: docker`), не строкой `toolchain: docker`. Порт — `"80"`, `build.skip: false`. Проект — Docker.
