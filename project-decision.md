## [2026-10-02] ADR-001: Инициализация системы памяти
**Контекст:**
Проект начал использовать MCP-сервер долгой памяти для Cursor.

**Решение:**
Созданы файлы памяти: passport, gotchas, BUGS, decisions, todo, STYLE.

**Альтернативы:**
- Не использовать память — риск потери контекста после /clear.
- Хранить в одном файле — сложно искать и поддерживать.

**Последствия:**
Cursor теперь может восстанавливать контекст между сессиями.

## [2026-10-02] ADR-002: Стек v1 Mini App
**Контекст:**
PRD «Подземные богатства» — idle-шахта в Max Mini App, полный функционал v1.

**Решение:**
Монорепо pnpm: Vite/React/TS/Tailwind/shadcn + Fastify/Postgres/Redis. Код в `Разработка/Подземные богатства`. OQ: окно босса 15м, один тип босса с разными HP по слотам, престиж сбрасывает шахту/апгрейды/помощников, удар с cooldown 0.8с без энергии.

**Альтернативы:**
- Vue клиент; Nest вместо Fastify; без Redis (только PG).

**Последствия:**
Единый `@pb/shared` для формул/баланса; Boss Raid в Redis; Max auth через initData (+dev bypass).

## [2026-10-02] ADR-003: Память проекта через MD-файлы
**Контекст:**
Нужно учитывать состояние проекта между сессиями агента.
**Решение:**
Источник правды: `project-passport.md`, `project-decision.md`, `gotchas.md`, `BUGS.md`, `STYLE.md`, `todo.md`, `README.md`. При значимых решениях/багах — append в decisions/gotchas/BUGS; STYLE и passport обновлять.
**Альтернативы:** только чат-контекст / только MCP memory.
**Последствия:** Агент обязан читать и обновлять эти файлы в работе над проектом.
